# Claude Usage Monitoring

This glossary defines the usage information shown by the extension and the planned PWA.

## Language

**Usage**:
The amount of a Claude allowance consumed during its usage window, shown as a percentage when available.
_Avoid_: Activity, API cost

**Remaining allowance**:
The portion of a Claude usage allowance that is still available in its current window. It does not imply a guaranteed number of remaining messages.
_Avoid_: Remaining messages, remaining tokens

**Reset time**:
The time when a usage window resets and its allowance becomes available again.
_Avoid_: Refresh time
